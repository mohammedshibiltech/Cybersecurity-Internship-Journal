# Topics Studied

## 1. What is Cybersecurity?

Cybersecurity is the practice of protecting:

- Networks
- Systems
- Applications
- Digital assets

from unauthorized access, cyber attacks, malware, and data breaches.

### Objectives

- Maintain Confidentiality
- Maintain Integrity
- Maintain Availability

(CIA Triad)

Methods include:

- Encryption
- Authentication
- Access Control

---

## 2. Domains of Cybersecurity

Some major domains include:

- Offensive Security (Red Team)
- Defensive Security (Blue Team)
- Cloud Security
- Application Security (AppSec)
- Governance, Risk & Compliance (GRC)

---

## 3. SOC (Security Operations Center)

SOC is responsible for:

- Monitoring
- Detection
- Analysis
- Incident Response

### Technologies

**SIEM**

Collects logs from multiple organizational assets for centralized analysis.

**EDR**

Endpoint Detection and Response solution installed on endpoints for threat detection and response.

### Roles

- SOC Analyst
- Incident Responder
- Threat Hunter
- SOC Manager

---

## 4. VAPT

VAPT stands for:

**Vulnerability Assessment and Penetration Testing**

### Vulnerability Assessment

Identifies weaknesses across systems and applications.

Focus:

"What vulnerabilities exist?"

### Penetration Testing

Attempts to exploit discovered weaknesses.

Focus:

"Can they actually be exploited?"

---

## Standard VAPT Workflow

1. Scoping & Planning
2. Information Gathering
3. Vulnerability Analysis
4. Exploitation
5. Post Exploitation
6. Reporting & Remediation

---

## Types of VAPT

### Network VAPT

- External
- Internal

### Web Application VAPT

Focus:

- Websites
- Web Applications

Reference:

- OWASP Top 10
- Burp Suite

### Mobile Application VAPT

- Android
- iOS

Reference:

- OWASP Mobile Top 10

### Cloud VAPT

Targets cloud infrastructure such as AWS and GCP.

### API VAPT

Tests APIs that enable communication between services.

### Thick Client VAPT

Assesses desktop applications interacting with remote servers.

### IoT & Embedded Systems

Tests smart and embedded devices for vulnerabilities.
